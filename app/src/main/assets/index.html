Del reloj al territorio

  1. 1Graba el entrenamientoCon tu reloj, ciclocomputador o aplicación habitual.
  2. 2Sincroniza la aplicación del fabricanteEn Android, podrá compartir la sesión mediante Health Connect.
  3. 3Autoriza o importa la rutaHealth Connect requiere tu aprobación. También puedes importar GPX o TCX directamente.

SuuntoEntrenamiento → menú de tres puntos → exportar GPX.

COROSActividad → menú → Export Data → GPX o TCX.

Otras marcasExporta el entrenamiento con ruta GPS en GPX o TCX.

La conexión automática llegará mediante Health Connect y APIs autorizadas. El importador evita que el mismo archivo vuelva a sumar si se selecciona más de una vez.
